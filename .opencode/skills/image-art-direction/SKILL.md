# Direção Imagem

Cada imagem tem função, origem licenciada e recorte intencional. Referência orienta estilo; não vira publicação.

## Quando usar
- Trabalhar com assets (logo, conteúdo, referência).
- Escolher recorte, proporção e área de texto sobre foto.
- Decidir uso de imagem gerada por IA.

## Processo
1. Classifique cada asset: logo, conteúdo ou referência. Referência não é material publicável sem mudança explícita de finalidade pelo usuário.
2. Defina papel narrativo: produto, espaço, processo, atmosfera. Proporção, ponto focal, iluminação, temperatura, área livre para texto. Nunca cortar rosto, produto ou informação relevante "para caber no card".
3. Logo oficial preservado: sem redesenho, distorção ou filtro. Use path local de publicação fornecido pela ferramenta — nunca URL assinada temporária. Sem foto adequada → composição tipográfica honesta, não URL inventada.
4. Geração de imagem: só com autorização, modelo configurado e ferramenta disponível. Imagem sintética nunca apresentada como equipe, imóvel, prato real ou resultado clínico. Ilustração identificada quando necessário.

## Checks
- Licença, finalidade, correspondência com o negócio, recorte mobile/desktop, contraste sobre foto, alt, tamanho.
- Nunca alegar ter visto a imagem sem acesso visual real.

## Anti-patterns
- Stock genérico como prova de instalações; redesenho de marca; referência publicada sem permissão; SVG inseguro; hotlink externo; custo implícito de geração sem autorização.

## DoD
Cada imagem com função e origem autorizada; logo íntegro; paths publicáveis; recortes/alternativas acessíveis; ausência de evidência visual declarada.
