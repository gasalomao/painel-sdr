## 🎯 Perguntas Frequentes (FAQ)

### Geral

**P: Quanto tempo leva para criar um site?**  
R: Em média 5-10 minutos para o primeiro resultado. [Ver métricas](./EXEMPLOS_PRATICOS_SITE_STUDIO.md#métricas-de-desenvolvimento)

**P: Posso usar meu próprio domínio?**  
R: Sim, através do Cloudflare Pages. [Ver deploy](./DOCUMENTACAO_SITE_STUDIO.md#deploy-publicação)

**P: Quantas revisões posso fazer?**  
R: Ilimitadas. Cada edição cria uma nova revisão. [Ver revisões](./DOCUMENTACAO_SITE_STUDIO.md#criação-de-revisão)

**P: Posso voltar para uma versão anterior?**  
R: Sim, via sistema de revisões e checkpoints. [Ver checkpoints](./DOCUMENTACAO_SITE_STUDIO.md#ferramentas-de-gestão)

### Técnico

**P: Quais tecnologias são usadas?**  
R: React 18+ + TypeScript + Vite + Tailwind CSS. [Ver stack](./DOCUMENTACAO_SITE_STUDIO.md#stack-tecnológico)

**P: Posso adicionar bibliotecas externas?**  
R: Não, apenas as dependências fixas. [Ver limitações](./DOCUMENTACAO_SITE_STUDIO.md#funcionais)

**P: Como funciona o sistema de budget?**  
R: Limita tokens e rodadas por run. [Ver budget](./DOCUMENTACAO_SITE_STUDIO.md#sistema-de-orçamento-budget)

**P: O que é modo Patch Only?**  
R: Modo otimizado para edições pontuais. [Ver explicação](./DOCUMENTACAO_SITE_STUDIO.md#modo-patch-only-ativado-automaticamente)

### Impeccable Design

**P: O que é Impeccable Design?**  
R: Sistema anti-template para sites originais. [Ver sistema](./DOCUMENTACAO_SITE_STUDIO.md#sistema-impeccable-design)

**P: Como ativo Impeccable?**  
R: Automaticamente por tags ou manualmente. [Ver ativação](./DOCUMENTACAO_SITE_STUDIO.md#ativação)

**P: Impeccable afeta performance?**  
R: Não, apenas orienta o design. [Ver fluxo](./DIAGRAMAS_ARQUITETURA_SITE_STUDIO.md#fluxo-impeccable-design)

### Problemas

**P: Build está falhando, e agora?**  
R: Agent corrige automaticamente. [Ver troubleshooting](./GUIA_RAPIDO_SITE_STUDIO.md#build-failed)

**P: Como cancelo um run travado?**  
R: Via API de cancelamento. [Ver debug](./GUIA_RAPIDO_SITE_STUDIO.md#cancelar-run-travado)

**P: Imagens não aparecem no site?**  
R: Verifique o path público do asset. [Ver solução](./EXEMPLOS_PRATICOS_SITE_STUDIO.md#cenário-2-imagens-não-carregam)
