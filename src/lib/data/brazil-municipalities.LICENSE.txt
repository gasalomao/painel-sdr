Format: UTF-8 JSON array of [name, uf, latitude, longitude] tuples.
Transformation: preserve source municipality order, names and coordinate precision;
join municipios.codigo_uf to estados.codigo_uf for the two-letter UF; omit all
other fields. No coordinates are inferred and no municipalities are dropped.
All data is bundled locally; use requires no network provider or API key.

Count: 5,571 municipalities across 27 UFs.
The upstream README still says 5,570. This pinned commit adds Boa Esperança do
Norte/MT (IBGE 5101837), so the actual source contains 5,571 unique rows.
This is a community-maintained dataset, not an official IBGE publication;
coordinates are municipality reference points, not borders or road distances.
Updates must explicitly pin a new source commit and revalidate the local tests.
